## 🚀 Projetos em destaque

### Cake Fast AI Receipt Reader
**PHP | OpenAI API | Inteligência Artificial**

Projeto experimental para leitura de cupons fiscais utilizando inteligência artificial e processamento de imagens.

- Envio de imagens JPEG para análise.
- Extração de informações fiscais.
- Integração com a API da OpenAI.
- Estudos para otimização de precisão e consumo de tokens.

[Ver projeto no GitHub](https://github.com/edson-freitas-j/cakefast-ai-receipt-reader)

### Controle Cake
**Kotlin | PHP | MariaDB | Android**

Aplicação desenvolvida para auxiliar na gestão financeira e operacional de um pequeno negócio.

- Aplicativo Android.
- Integração com backend PHP.
- Persistência de dados em MariaDB.
- Comunicação entre aplicativo e servidor.

### Gmail Bulk Cleaner
**JavaScript | Google Apps Script | Gmail API**

Automação desenvolvida para gerenciamento de grandes volumes de mensagens no Gmail.

- Listagem de mensagens em lotes.
- Exclusão em massa utilizando a API do Gmail.
- Automatização de tarefas repetitivas.

### Arduino Nikon Remote
**Arduino | Eletrônica | Infravermelho**

Projeto de automação eletrônica para controle remoto de disparo de câmera fotográfica Nikon por meio de Arduino e sinal infravermelho.
